# Ten-day commit plan

The progress tracker counts commits made on **10 different days**. This plan gives each day a useful, reviewable change. Commit only work that has actually been completed; do not backdate or split changes just to change the day count.

| Day | Example commit focus |
| --- | --- |
| 1 | Add MERN workspace scaffold and setup guide |
| 2 | Add MongoDB tenant, user, and customer models |
| 3 | Add account registration and password hashing |
| 4 | Add sign-in, token handling, and authenticated API middleware |
| 5 | Add tenant-scoped customer list and create endpoints |
| 6 | Add customer dashboard, validation, and delete flow |
| 7 | Add billing plan model and API |
| 8 | Add usage records and invoice calculation |
| 9 | Add invoice display and proof-of-total prototype |
| 10 | Complete documentation, demo flow, and final cleanup |

Adjust this list to match the mentor's requirements. Push each day's meaningful commit to the connected repository so the progress tracker can see it.
